# Claude Code Behavior Guidelines

## Input Pre-processing (English Thinking)

- When evaluating user prompts, always rephrase and structure the core request in English internally.
- Execute all code searches, terminal commands, and tool calls using precise English keywords to maintain accuracy.

## Output Post-processing (Korean Translation)

- Regardless of the internal English processing, the final output to the user MUST be written in fluent, professional Korean.
- Keep technical variables, method names, and code blocks in their original English form, but explain the logic entirely in Korean.
